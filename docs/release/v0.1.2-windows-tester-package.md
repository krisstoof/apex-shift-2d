# Apex Shift 2D v0.1.2 - Windows Tester Package Checklist

## Goal

Prepare a Windows tester package for `Apex Shift 2D v0.1.2` that a tester can download, open, and use to start smoke testing immediately.

---

## Package Contents

Include the following files in the tester package:

- game build for Windows,
- `README.md`,
- `CHANGELOG.md`,
- `KNOWN_ISSUES.md`,
- `TESTER_INSTRUCTIONS.md`,
- `docs/testing/v0.1.2-smoke-test.md`.

If the build produces a `.pck` file, include it next to the `.exe`.

Suggested package layout:

```text
ApexShift2D_v0.1.2_windows_test/
├─ ApexShift2D.exe
├─ ApexShift2D.pck
├─ README.md
├─ CHANGELOG.md
├─ KNOWN_ISSUES.md
├─ TESTER_INSTRUCTIONS.md
└─ docs/
   └─ testing/
      └─ v0.1.2-smoke-test.md
```

---

## Build Checks

Before packaging, verify:

- the Windows build starts successfully,
- the game opens to the start menu,
- the start menu shows `Apex Shift 2D v0.1.2`,
- the application log shows `[APP] Apex Shift 2D v0.1.2`,
- New Game reaches gameplay,
- the build does not crash in the first minute of test play.

---

## Packaging Rules

Do not include unnecessary developer files, such as:

- `.git/`,
- `.godot/`,
- raw import cache files,
- temporary files,
- unrelated developer logs,
- old builds,
- old benchmark artifacts,
- unrelated working files.

Keep the package focused on what the tester needs.
