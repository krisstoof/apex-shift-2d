# Apex Shift 2D v0.1.2 - Smoke Test Checklist

## Purpose

This checklist verifies the main playable and testable features of `Apex Shift 2D v0.1.2` in one short test session.

It is not a full regression test. The goal is to quickly confirm that the build starts, the main UI works, inventory and storage behave correctly, and the core gameplay loop is still usable.

Estimated time: 20-35 minutes.
