# Changelog

## v0.1.2

### Added
- Expanded HUD presentation for the current test build.
- Resource icons in the UI for clearer item feedback.
- A simple inventory flow that supports carrying and managing items.
- An inventory screen for inspecting carried items.
- Storage box support for extended item handling.
- Save and load support for inventory and storage box state.
- Improved debug panel diagnostics for testing and iteration.

### Changed
- Release identity updated to `Apex Shift 2D v0.1.2`.
- The prototype now makes the current inventory and storage systems easier to inspect during manual testing.

### Notes
- This changelog documents the visible release state of the current prototype build.
- Older release notes are intentionally left untouched when they describe past versions.
